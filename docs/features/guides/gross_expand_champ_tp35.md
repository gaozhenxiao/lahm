# 毛利率扩张通宵冠军止盈35%（gross_expand_champ_tp35）

通宵因子挖掘（2026-07-31 → 2026-08-01）当前冠军。  
**入场**：毛利率环比扩张 + 净利率达标后的 60 日突破。  
**出场**：固定止盈 35%（另有持有上限 / 止损）。

> 同类入场高原（如 `gross_expand_brk60_m17_np10_lag29` 及 lag/hold/imp/m* 微调）**不再继续挖参**——属于参数调优，极易过拟合。后续若再挖，应换真正不同的结构，而不是在 1.80 附近拧螺丝。

## 怎么选股（逐步）

股票池：沪深 300 成分（回测默认 `universe=hs300`）。对每只股票逐日检查，**同时满足**才产生买入信号：

1. **财务事件**：最新一期利润表披露日，毛利率 `gpMargin` 相对上一期上升 ≥ **0.006**（0.6 个百分点）  
2. **毛利率水平**：当期毛利率 ≥ **0.17**（17%）  
3. **净利率过滤**：入场当日（前向填充后的）净利率 ≥ **0.10**（10%）  
4. **热窗**：上述财务事件发生后的 **29 个交易日**内（`funda_lag=29`）才允许交易信号  
5. **技术确认**：收盘价 **≥ 昨日往前 60 日最高价**，且收盘价 **> MA20**  
6. **组合约束**：最多同时持有 8 只，等权；有空位才开新仓  

出场（任一触发）：

| 规则 | 参数 |
|---|---|
| 固定止盈 | 相对成本价 +**35%** |
| 止损 | −**12%** |
| 时间止损 | 持有满 **51** 个交易日 |

信号实现：`signal_gross_expand_break`（`app/services/factors/signal_specs.py`）。  
笔构建：`runner.build_legs_from_entries`（支持 `take_profit` / `trail_stop`）。

## 举例：当时为什么选上「沪电股份」

回测成交记录中的真实一笔（`gross_expand_champ_tp35_trade_history.csv`）：

| 项目 | 内容 |
|---|---|
| 标的 | **sz.002463 沪电股份** |
| 开仓 | 2019-08-30，约 18.23 元 |
| 清仓 | 2019-09-23，约 24.61 元 |
| 收益 | **+35.0%**（触达固定止盈） |
| 持有 | 约 24 个自然日 |
| 当日组合贡献 | NAV +4.38% |

**开仓日当天，规则如何打勾：**

1. **财务刚披露（2019-08-29）**  
   - 上一期毛利率约 **25.9%** → 新一期约 **29.2%**，环比提升约 **+3.3 个百分点** ≫ 0.6  
   - 新一期净利率约 **15.3%** ≥ 10%  
2. **热窗**：披露次日（08-30）仍在 29 日窗口内  
3. **突破**：08-30 收盘 18.23 ≥ 前一日滚动 60 日高约 **18.08**，且明显高于 MA20（约 16.11）  
4. **组合有空位**：按等权 1/8 开仓  

之后约三周内价格涨到成本价的 1.35 倍，触发止盈离场——这正是相对「无止盈原冠」Sharpe 抬升的来源：截住了一部分回吐。

同类止盈离场还可对照（同文件）：天齐锂业 `sz.002466`（2022-06-07→07-04，+35%）、中国巨石 `sh.600176`（2026-04-10→05-25，+35%）等。
