# 营收环比扩张突破（rev_qoq_break）

主营业务收入环比上升后突破（直接营收，非净利代理）。

标签：`基本面` · `技术面` · `营收` · `新结构`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **合同负债/预收款扩张**：环比 ≥ 8.00%（新准则合同负债与旧准则预收款合并口径）
3. **营收环比**：主营业务收入相对上一披露期上升（非净利代理）
4. **财务热窗**：上述财务事件发生后的 **28** 个交易日内才允许技术信号
5. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
6. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
7. **出场（任一触发）**：止损 **−12.00%**；持有满 **35** 个交易日

信号实现：`signal_rev_qoq_break`（`app/services/factors/signal_specs.py`）。
