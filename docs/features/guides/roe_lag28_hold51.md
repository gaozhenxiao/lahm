# ROE扩张(lag28持有51)（roe_lag28_hold51）

ROE扩张热窗28 + 持有51。

标签：`基本面` · `技术面` · `ROE`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **质量底线**：ROE ≥ **10.00%**
3. **ROE 改善**：相对上一披露期上升 ≥ **0.30%**（百分点/小数按数据口径）
4. **财务热窗**：上述财务事件发生后的 **28** 个交易日内才允许技术信号
5. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
6. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
7. **出场（任一触发）**：止损 **−12.00%**；持有满 **51** 个交易日

信号实现：`signal_roe_expand_breakout`（`app/services/factors/signal_specs.py`）。
