# 需求定价×趋势回踩（demand_pricing_pullback）

需求×定价热窗口内，MA60上行趋势中回踩站上MA20。

标签：`基本面` · `技术面` · `回踩` · `趋势` · `合同负债` · `毛利率`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
3. **利润率水平**：毛利率（或规则指定利润率）≥ **15.00%**
4. **净利率过滤**：净利率 ≥ **6.00%**
5. **合同负债/预收款扩张**：同比 ≥ 12.00% 或 环比 ≥ 8.00%（新准则合同负债与旧准则预收款合并口径）
6. **双确认**：合同负债扩张热窗 ∩ 毛利率扩张热窗（需求 × 定价）
7. **财务热窗**：上述财务事件发生后的 **30** 个交易日内才允许技术信号
8. **图形·趋势回踩**：MA60 上行；近 20 日回撤 ≥ **3.00%**；收盘重新站上 MA20 且仍在 MA60 上方
9. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
10. **出场（任一触发）**：止损 **−12.00%**；持有满 **35** 个交易日

信号实现：`signal_demand_pricing_break`（`app/services/factors/signal_specs.py`）。

## 举例：回测里真实成交的一腿

来源：`data/factors/demand_pricing_pullback_trade_history.csv`

| 项目 | 内容 |
|---|---|
| 标的 | **sz.002050** |
| 开仓 | 2025-09-05，约 30.43 元 |
| 清仓 | 2025-11-03，约 48.36 元 |
| 单腿涨跌 | **58.93%** |
| 当日组合贡献 | NAV 7.37% |
| 出场备注 | hold_end；买入2025-09-05 成本价30.4283 |

**开仓信号备注**：需求定价双确认突破

解读：开仓日报价满足「财务闸门 + 技术图形」；清仓由止盈/止损/到期之一触发。案例用于理解规则，不构成推荐。
