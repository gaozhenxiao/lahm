# 红利 ETF 倾斜网格（dividend_etf_slope_grid）

在**红利类 ETF**上做向上倾斜网格，与策略中心「红利倾斜网格」同源（v3 最优参数）。

默认标的 `515080`（华泰柏瑞红利 ETF），缺失时可切换 `512890` / `510880` / `515180`。

## 怎么交易（逐步）

本因子**不选个股**，只交易红利 ETF：

1. **中枢**：每日 `center = max(旧中枢, MA90)`，**只升不降**（顺势抬高，避免下跌里死扛摊薄）
2. **加仓**：收盘价相对中枢跌超 **0.8%** → 加一档（最多 10 档）
3. **减仓**：相对中枢涨超 **0.8%** → 减一档，但至少保留 **2** 档底仓
4. **初始**：建仓 `max(2, 10/2)=5` 档

产物里有「价位买卖点」图：价格线 + 橙色中枢 + 红三角买 / 绿倒三角卖。

## 思路

红利慢牛/震荡里，纯网格容易在下跌中空仓、在反弹里踏空。倾斜中枢把「卖出基准」不断上移，并用底仓保住上行敞口。

## 成本与记账

- 佣金：**万分之一**（买卖）
- 印花税：**ETF 免征**
- 收盘成交；空仓/现金部分按约 1.4% 年化计息（回测口径）

## 怎么跑

```bash
python scripts/backtest_dividend_etf_slope_grid.py
python scripts/backtest_dividend_etf_slope_grid.py --etf 512890
```

产物：`data/factors/dividend_etf_slope_grid_*`（净值图、买卖点图、操作历史、日度 CSV）

## 关键参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `etf_code` | 515080 | 交易 ETF |
| `step_pct` | 0.8% | 相对中枢的加/减档步长 |
| `n_grids` | 10 | 最大档数 |
| `min_layers` | 2 | 最少保留档数（底仓） |
| `ma_center` | 90 | 抬升中枢用的均线窗口 |
| `position_logic` | slope_up_grid | 主逻辑名 |
