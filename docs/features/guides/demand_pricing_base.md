# 需求定价×横盘突破（demand_pricing_base）

合同负债扩张×毛利率扩张热窗口内，横盘收窄后箱体突破。

标签：`基本面` · `技术面` · `横盘` · `突破` · `合同负债` · `毛利率`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
3. **利润率水平**：毛利率（或规则指定利润率）≥ **15.00%**
4. **合同负债/预收款扩张**：同比 ≥ 12.00% 或 环比 ≥ 8.00%（新准则合同负债与旧准则预收款合并口径）
5. **双确认**：合同负债扩张热窗 ∩ 毛利率扩张热窗（需求 × 定价）
6. **财务热窗**：上述财务事件发生后的 **28** 个交易日内才允许技术信号
7. **图形·横盘突破**：近 `60` 日振幅 ≤ **24.00%**，收盘突破箱体上沿，且站上均线
8. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
9. **出场（任一触发）**：止损 **−12.00%**；持有满 **40** 个交易日

信号实现：`signal_demand_pricing_break`（`app/services/factors/signal_specs.py`）。

## 举例：回测里真实成交的一腿

来源：`data/factors/demand_pricing_base_trade_history.csv`

| 项目 | 内容 |
|---|---|
| 标的 | **sh.601360** |
| 开仓 | 2024-09-30，约 8.558 元 |
| 清仓 | 2024-12-02，约 12.91 元 |
| 单腿涨跌 | **50.85%** |
| 当日组合贡献 | NAV 6.36% |
| 出场备注 | hold_end；买入2024-09-30 成本价8.5584 |

**开仓信号备注**：需求定价双确认突破

解读：开仓日报价满足「财务闸门 + 技术图形」；清仓由止盈/止损/到期之一触发。案例用于理解规则，不构成推荐。

## 怎么跑

```bash
python scripts/run_new_factors.py --only demand_pricing_base --limit 40
python scripts/run_new_factors.py --only demand_pricing_base --limit 0
```
