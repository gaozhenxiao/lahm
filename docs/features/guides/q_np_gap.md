# 正式季报单季净利润断层式跨越增长（q_np_gap）

正式季报单季净利润断层式跨越增长：财务热窗0日；入场=60日高+MA20；持有20日；止损15%；无固定止盈。

备注：正式季报（非预告）事件：利润表累计净利差分得单季 NP，单季同比≥100% 且体现断层（上年同季增速不高或单季环比跨越）；按实际/公告日 asof 对齐防前视；排除单季亏损与基期亏损伪翻倍。等权持有约20个交易日。

标签：`正式季报` · `单季净利` · `事件` · `利润断层` · `基本面` · `非预告`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **财务热窗**：上述财务事件发生后的 **0** 个交易日内才允许技术信号
3. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
4. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
5. **出场（任一触发）**：止损 **−15.00%**；持有满 **20** 个交易日

信号实现：`signal_q_np_gap`（`app/services/factors/signal_specs.py`）。
