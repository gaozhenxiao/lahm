# 国家队因子（national_team）

做的是一件事：**尽量跟着「国家队 / 汇金」真实在买什么走，而不是自己猜底。**

## 信号看什么

主要看汇金占比较高的沪深300 ETF 份额变化（默认加权）：

- **510300**（权重最高）  
- **510310**  
- **510330**  

份额明显抬升 → 偏增仓信号；明显下降 → 偏减仓。  
也会结合精选新闻 / 政策日历、汇金季报公告等，作为「火花」或延长持仓的辅助，而不是单独瞎开仓。

## 交易买什么（时代篮子）

信号用 300ETF 份额，**具体买入标的随时代切换**：

1. 早期：更偏宽基（如上证50）  
2. 中间：沪深300 等宽基  
3. 近年：更贴近实际风格 —— **银行 + 科创** 一类篮子  

也就是说：信号是「国家队在动」，仓位落在「当时更像国家队在做的方向」。

## 仓位怎么管

页面回测里常见两套逻辑：

### long_hold（粘持）
- 需要较强政策 / 精选新闻火花才试探开仓  
- 份额确认后可加到更高仓  
- 默认不靠「恐慌暴跌」直接开仓  
- 交易很少，吃大段趋势，回撤可能更深  

### continuous（连续仓）
- 战役底仓 + 随份额强弱连续加减  
- 允许在份额再度走强时反复进出  
- 交易更勤，夏普往往更好、回撤相对浅一些  

列表「回测摘要」里会分别给出两套指标；净值图也分粘持 / 连续。

## 和「暴跌抄底」有什么不同

- **国家队**：跟「谁在买」（份额、政策）  
- **暴跌抄底**：跟「跌得惨不惨、贵不贵」  

国家队更像跟庄/跟救市节奏；抄底更像估值约束下的逆向择时。

## 怎么用页面

- **计算信号**：得到当日 buy / sell / neutral 与强度  
- **净值·粘持 / 净值·连续**：看两套仓位逻辑的历史净值  
- **交易**：看开平加减仓流水（含净值）  
- **份额图**：看汇金相关 ETF 份额历史
