# 毛净利率严阈值(持有51)（gp_np_lag_hold51）

严阈值毛净利率 + 持有51。

标签：`基本面` · `技术面` · `毛利率` · `净利率`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
3. **净利率改善**：环比上升 ≥ **0.50%**
4. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
5. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
6. **出场（任一触发）**：止损 **−12.00%**；持有满 **51** 个交易日

信号实现：`signal_gp_np_expand_break`（`app/services/factors/signal_specs.py`）。

## 举例：回测里真实成交的一腿

来源：`data/factors/gp_np_lag_hold51_trade_history.csv`

| 项目 | 内容 |
|---|---|
| 标的 | **sh.601633 长城汽车** |
| 开仓 | 2020-09-08，约 15.43 元 |
| 清仓 | 2020-11-26，约 24.62 元 |
| 单腿涨跌 | **59.54%** |
| 当日组合贡献 | NAV 7.44% |
| 出场备注 | hold_end；买入2020-09-08 成本价15.4317 |

**开仓信号备注**：毛净利率双扩张突破

解读：开仓日报价满足「财务闸门 + 技术图形」；清仓由止盈/止损/到期之一触发。案例用于理解规则，不构成推荐。
