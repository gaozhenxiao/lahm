# 需求定价×横盘突破(净利)（demand_pricing_base_np）

需求×定价×净利率 + 横盘箱体突破。

标签：`基本面` · `技术面` · `横盘` · `突破` · `合同负债` · `毛利率`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
3. **利润率水平**：毛利率（或规则指定利润率）≥ **17.00%**
4. **净利率过滤**：净利率 ≥ **8.00%**
5. **合同负债/预收款扩张**：同比 ≥ 12.00% 或 环比 ≥ 8.00%（新准则合同负债与旧准则预收款合并口径）
6. **双确认**：合同负债扩张热窗 ∩ 毛利率扩张热窗（需求 × 定价）
7. **财务热窗**：上述财务事件发生后的 **29** 个交易日内才允许技术信号
8. **图形·横盘突破**：近 `60` 日振幅 ≤ **22.00%**，收盘突破箱体上沿，且站上均线
9. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
10. **出场（任一触发）**：固定止盈 +**35.00%**；止损 **−12.00%**；持有满 **51** 个交易日

信号实现：`signal_demand_pricing_break`（`app/services/factors/signal_specs.py`）。

## 举例：回测里真实成交的一腿

来源：`data/factors/demand_pricing_base_np_trade_history.csv`

| 项目 | 内容 |
|---|---|
| 标的 | **sz.002625** |
| 开仓 | 2024-09-10，约 18.87 元 |
| 清仓 | 2024-10-08，约 27.23 元 |
| 单腿涨跌 | **44.33%** |
| 当日组合贡献 | NAV 5.54% |
| 出场备注 | take_profit；买入2024-09-10 成本价18.8676 |

**开仓信号备注**：需求定价双确认突破

解读：开仓日报价满足「财务闸门 + 技术图形」；清仓由止盈/止损/到期之一触发。案例用于理解规则，不构成推荐。
