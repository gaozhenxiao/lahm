# 毛净利率严阈值横盘(持有35)（gp_np_lag_base_hold35）

严阈值毛净利率横盘突破 + 持有加长。

标签：`基本面` · `技术面` · `毛利率` · `横盘`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
3. **净利率过滤**：净利率 ≥ **5.00%**
4. **净利率改善**：环比上升 ≥ **0.50%**
5. **财务热窗**：上述财务事件发生后的 **25** 个交易日内才允许技术信号
6. **图形·收窄后突破**：振幅 ≤ 22.00% 的横盘背景下，收盘 ≥ 昨日起算 **60** 日高，且 > MA20
7. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
8. **出场（任一触发）**：止损 **−12.00%**；持有满 **35** 个交易日

信号实现：`signal_gp_np_tight_base`（`app/services/factors/signal_specs.py`）。

来源：`data/factors/gp_np_lag_base_hold35_trade_history.csv`

| 单笔涨跌 | **55.98%** |

**开仓信号备注**：严标准毛净利率横盘突破

解读：开仓日报价满足「财务闸门 + 技术图形」；清仓由止盈/止损/到期之一触发。案例用于理解规则，不构成推荐。
