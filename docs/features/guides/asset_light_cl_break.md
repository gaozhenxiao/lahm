# 轻资产合同负债突破（asset_light_cl_break）

资产扩张不快 + 合同负债扩张后突破（偏软件/服务/订金型）。

标签：`基本面` · `技术面` · `合同负债` · `轻资产` · `新结构`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **合同负债/预收款扩张**：同比 ≥ 15.00% 或 环比 ≥ 8.00%（新准则合同负债与旧准则预收款合并口径）
3. **轻资产约束**：总资产同比 ≤ **15.00%**（或缺失视为通过）
4. **结构**：轻资产扩张约束下的合同负债/预收款扩张
5. **财务热窗**：上述财务事件发生后的 **28** 个交易日内才允许技术信号
6. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
7. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
8. **出场（任一触发）**：止损 **−12.00%**；持有满 **40** 个交易日

信号实现：`signal_asset_light_cl_break`（`app/services/factors/signal_specs.py`）。
