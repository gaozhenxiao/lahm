# 毛净双扩张峰(止盈20%)（gp_np_peak_tp20）

gp_np次峰 × 止盈20%。

标签：`基本面` · `技术面` · `毛利率` · `净利率` · `出场`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.60%**
3. **利润率水平**：毛利率（或规则指定利润率）≥ **17.00%**
4. **净利率过滤**：净利率 ≥ **10.00%**
5. **净利率改善**：环比上升 ≥ **0.50%**
6. **财务热窗**：上述财务事件发生后的 **29** 个交易日内才允许技术信号
7. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
8. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
9. **出场（任一触发）**：固定止盈 +**20.00%**；止损 **−12.00%**；持有满 **51** 个交易日

信号实现：`signal_gp_np_expand_break`（`app/services/factors/signal_specs.py`）。
