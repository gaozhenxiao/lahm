# 红利 ETF 波段（dividend_etf_swing）

在**红利类 ETF**上做防守型波段，而不是选股。默认标的为华泰柏瑞红利 ETF（`515080`），若行情缺失会依次尝试 `512890` / `510880` 等。

> 当前环境若外网 ETF 拉取失败，会自动回退到本地 **BANK4 银行等权** 等红利风格代理做规则验证；网络恢复后重跑 `scripts/backtest_dividend_etf_swing.py` 即可切回真实 ETF。

## 怎么选股（逐步）

本因子**不选个股**，只交易红利类 ETF（默认 `515080`，缺失时尝试 `512890` / `510880`）：

1. **标的**：红利 ETF（或本地 BANK4 等红利风格代理，仅验证规则时）  
2. **趋势过滤**：收盘站上 **MA60**，避免长期阴跌里左侧摸底  
3. **图形·回踩确认**：价格回踩后重新站上 **MA20**（主逻辑 `ma_pullback`）  
4. **出场（任一）**：连续跌破 MA20；止损约 **−8%**；持有满约 **25** 日  

可选对比逻辑 `trend_follow`：MA20 上穿且均线多头排列时持有，跌破慢均线离场。

## 思路

红利 ETF 波动低于成长宽基，适合作为组合里的卫星/防守仓。

## 成本与记账

- 佣金：**万分之一**（买卖）  
- 印花税：**ETF 免征**  
- 收盘调仓；**隔夜仓**计下一交易日涨跌；空仓可按约 1.4% 年化货币利息  

## 怎么跑

```bash
python scripts/backtest_dividend_etf_swing.py
python scripts/backtest_dividend_etf_swing.py --etf 512890 --compare
```

产物：`data/factors/dividend_etf_swing_*`

## 使用建议

- 更适合作为总仓位的一部分（例如 20%～40% 上限），与股票侧进攻因子搭配  
- 红利风格失效、成长单边行情时，波段次数可能增多、超额有限——以回测夏普/回撤为准  
- 「计算信号」给出最近仓位建议（buy/hold/sell/neutral），需结合自身风控  

## 关键参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `etf_code` | 515080 | 交易 ETF |
| `ma_fast` / `ma_slow` | 20 / 60 | 快慢均线 |
| `hold_days` | 25 | 最长持有 |
| `stop_loss` | 8% | 相对开仓价止损 |
| `position_logic` | ma_pullback | 主逻辑 |
