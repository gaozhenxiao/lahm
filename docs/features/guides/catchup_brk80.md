# 毛净利差收敛(突破80)（catchup_brk80）

catchup × 80日突破。

标签：`基本面` · `技术面` · `毛利率` · `净利率`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
3. **财务热窗**：上述财务事件发生后的 **28** 个交易日内才允许技术信号
4. **图形·突破确认**：收盘 ≥ 昨日起算 **80** 日最高价，且收盘 > **MA20**
5. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
6. **出场（任一触发）**：止损 **−12.00%**；持有满 **51** 个交易日

信号实现：`signal_gross_net_catchup_break`（`app/services/factors/signal_specs.py`）。
