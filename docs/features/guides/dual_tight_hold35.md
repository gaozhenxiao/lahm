# 双改善严横盘突破(持有加长)（dual_tight_hold35）

严横盘双改善突破，持有期加长。

标签：`基本面` · `技术面` · `横盘`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **ROE 改善**：相对上一披露期上升 ≥ **0.30%**（百分点/小数按数据口径）
3. **利润率改善**：毛利率/净利率环比上升 ≥ **0.40%**
4. **图形·收窄后突破**：振幅 ≤ 18.00% 的横盘背景下，收盘 ≥ 昨日起算 **60** 日高，且 > MA20
5. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
6. **出场（任一触发）**：止损 **−12.00%**；持有满 **35** 个交易日

信号实现：`signal_dual_improve_base_break`（`app/services/factors/signal_specs.py`）。
