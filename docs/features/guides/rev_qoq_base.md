# 营收环比×横盘突破（rev_qoq_base）

主营收入环比上升热窗口内横盘突破。

标签：`基本面` · `技术面` · `横盘` · `突破` · `营收`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **质量底线**：ROE ≥ **6.00%**
3. **合同负债/预收款扩张**：环比 ≥ 8.00%（新准则合同负债与旧准则预收款合并口径）
4. **营收环比**：主营业务收入相对上一披露期上升（非净利代理）
5. **财务热窗**：上述财务事件发生后的 **28** 个交易日内才允许技术信号
6. **图形·横盘突破**：近 `60` 日振幅 ≤ **24.00%**，收盘突破箱体上沿，且站上均线
7. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
8. **出场（任一触发）**：止损 **−12.00%**；持有满 **35** 个交易日

信号实现：`signal_rev_qoq_break`（`app/services/factors/signal_specs.py`）。

## 怎么跑

```bash
python scripts/run_new_factors.py --only rev_qoq_base --limit 40
python scripts/run_new_factors.py --only rev_qoq_base --limit 0
```

产物：`data/factors/rev_qoq_base_*`
