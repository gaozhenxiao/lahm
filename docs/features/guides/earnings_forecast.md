# 业绩预告双路径因子（earnings_forecast）

围绕**业绩预告/快报公告**做事件驱动：超预期且位置不贵可尝试公告直买；否则等回撤再买。属于「事件基本面 + 价格位置」结构，不是纯量价。

## 怎么选股（逐步）

对每条有效预告，按三维打分，再决定路径：

1. **超预期幅度**  
   - 爆发：预告增速极高（默认阈值约 ≥100%）  
   - 较强：约 ≥30%  
   - 轻度：更低，通常不追高、只走回调路径  
2. **中长期位置**  
   - 两年涨幅 ≤ **40%** 才更倾向直买  
   - ≥ **100%** 一般不追（避免高位接飞刀）  
3. **短期涨幅**  
   - 较强档：公告附近短涨 ≤ **5%**  
   - 爆发档：≤ **10%**  
4. **路径选择**  
   - 三维都偏友好 → **公告直买**（收盘调仓）  
   - 否则 → 等公告后相对高点 **回撤 ≥8%** 再收盘买入  
5. **出场**：统一止损约 **15%**，持有约 **20** 个交易日（以因子参数为准）

## 举例：规则如何打勾（示意）

假设某票预告净利同比 +80%（较强档），两年涨幅 25%，公告日附近 3 日涨幅 2%：

1. 超预期：较强 ✓  
2. 中长期位置：未过热 ✓  
3. 短期涨幅：≤5% ✓  
→ 走**直买**路径；若短期已涨 12%，则改为等回撤 ≥8% 再买。

（具体成交案例见 `data/factors/earnings_forecast_trade_history.csv`。）

## 成本与调仓

- 佣金万一（双边）+ 卖出印花税千一  
- **收盘调仓**：当日盈亏只算调仓前隔夜仓
