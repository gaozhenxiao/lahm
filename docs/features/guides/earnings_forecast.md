# 业绩预告双路径因子（earnings_forecast）

是否**公告直买（追高）**综合三维：

| 维度 | 默认 |
|------|------|
| 超预期幅度 | 爆发 ≥100% / 较强 ≥30% / 轻度只回调 |
| 中长期位置 | 两年涨幅 ≤40% 才谈直买；≥100% 不追 |
| 短期涨幅 | 较强 ≤5%；爆发 ≤10% |

不满足 → **等公告后相对高点回撤 ≥8%** 再收盘买；统一止损约 **15%**，持有约 20 日。

## 成本

佣金万一 + 卖出印花税千一；收盘调仓。

```bash
python scripts/backtest_earnings_forecast_factor.py
```
