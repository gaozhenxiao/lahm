# 毛利率中档持有50(止损收紧)（gross_expand_mid_stop10）

中档改善 hold50 + 止损0.10。

标签：`基本面` · `技术面` · `毛利率`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.60%**
3. **利润率水平**：毛利率（或规则指定利润率）≥ **20.00%**
4. **财务热窗**：上述财务事件发生后的 **25** 个交易日内才允许技术信号
5. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
6. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
7. **出场（任一触发）**：止损 **−10.00%**；持有满 **50** 个交易日

信号实现：`signal_gross_expand_break`（`app/services/factors/signal_specs.py`）。
