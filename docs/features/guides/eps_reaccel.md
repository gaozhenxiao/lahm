# EPS再加速（eps_reaccel）

EPS同比从低位回升并改善。

标签：`基本面` · `EPS` · `加速`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **成长闸门**：净利/营收同比 ≥ **8.00%**
3. **增速加速**：同比相对上期再抬升 ≥ **5.00%**
4. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
5. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
6. **出场（任一触发）**：止损 **−12.00%**；持有满 **25** 个交易日

信号实现：`signal_eps_reaccel`（`app/services/factors/signal_specs.py`）。
