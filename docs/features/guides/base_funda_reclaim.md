# 横盘财务回踩（base_funda_reclaim）

长期横盘中出现财务好转后，回踩确认站上MA20（更早介入，不等突破）。

标签：`基本面` · `技术面` · `横盘` · `回踩` · `财报改善`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **ROE 改善**：相对上一披露期上升 ≥ **0.30%**（百分点/小数按数据口径）
3. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
4. **成长闸门**：净利/营收同比 ≥ **5.00%**
5. **增速加速**：同比相对上期再抬升 ≥ **5.00%**
6. **财务热窗**：上述财务事件发生后的 **25** 个交易日内才允许技术信号
7. **图形·收窄后突破**：振幅 ≤ 22.00% 的横盘背景下，收盘 ≥ 昨日起算 **60** 日高，且 > MA20
8. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
9. **出场（任一触发）**：止损 **−12.00%**；持有满 **25** 个交易日

信号实现：`signal_base_funda_reclaim`（`app/services/factors/signal_specs.py`）。

| 开仓 | 2016-06-06，约 8.722 元 |
| 清仓 | 2016-07-13，约 13.83 元 |
| 单笔涨跌 | **58.56%** |
| 当日组合贡献 | NAV 7.32% |
| 出场备注 | hold_end；买入2016-06-06 成本价8.7219 |

**开仓信号备注**：横盘中财务好转回踩确认

解读：开仓日报价满足「财务闸门 + 技术图形」；清仓由止盈/止损/到期之一触发。案例用于理解规则，不构成推荐。
