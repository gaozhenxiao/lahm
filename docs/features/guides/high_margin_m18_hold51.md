# 高净利率门槛0.18(持有51)（high_margin_m18_hold51）

更高净利率门槛 + 持有51。

标签：`基本面` · `技术面` · `净利率`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率水平**：毛利率（或规则指定利润率）≥ **18.00%**
3. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
4. **动量下限**：动量指标 ≥ **-2.00%**
5. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
6. **出场（任一触发）**：止损 **−12.00%**；持有满 **51** 个交易日

信号实现：`signal_high_margin_breakout`（`app/services/factors/signal_specs.py`）。
