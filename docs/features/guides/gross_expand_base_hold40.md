# 毛利率扩张横盘(持有40)（gross_expand_base_hold40）

毛利率扩张横盘突破 + 持有加长。

标签：`基本面` · `技术面` · `毛利率` · `横盘`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
3. **利润率水平**：毛利率（或规则指定利润率）≥ **20.00%**
4. **财务热窗**：上述财务事件发生后的 **20** 个交易日内才允许技术信号
5. **图形·收窄后突破**：振幅 ≤ 22.00% 的横盘背景下，收盘 ≥ 昨日起算 **60** 日高，且 > MA20
6. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
7. **出场（任一触发）**：止损 **−12.00%**；持有满 **40** 个交易日

信号实现：`signal_gross_expand_base_break`（`app/services/factors/signal_specs.py`）。
