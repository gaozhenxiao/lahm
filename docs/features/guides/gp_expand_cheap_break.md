# 毛利率扩张低估突破（gp_expand_cheap_break）

毛利率扩张且估值不高时突破。

标签：`基本面` · `技术面` · `毛利率` · `估值`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **估值闸门**：PE 历史分位 ≤ **45.00%**（窗口 `756` 交易日）
3. **利润率改善**：毛利率/净利率环比上升 ≥ **0.50%**
4. **利润率水平**：毛利率（或规则指定利润率）≥ **18.00%**
5. **财务热窗**：上述财务事件发生后的 **25** 个交易日内才允许技术信号
6. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
7. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
8. **出场（任一触发）**：止损 **−12.00%**；持有满 **25** 个交易日

信号实现：`signal_gp_expand_cheap_break`（`app/services/factors/signal_specs.py`）。

## 举例：回测里真实成交的一腿

来源：`data/factors/gp_expand_cheap_break_trade_history.csv`

| 项目 | 内容 |
|---|---|
| 标的 | **sh.600570** |
| 开仓 | 2024-09-27，约 20.53 元 |
| 清仓 | 2024-11-08，约 31.26 元 |
| 单腿涨跌 | **52.28%** |
| 当日组合贡献 | NAV 6.54% |
| 出场备注 | hold_end；买入2024-09-27 成本价20.5280 |

**开仓信号备注**：毛利率扩张低估突破

解读：开仓日报价满足「财务闸门 + 技术图形」；清仓由止盈/止损/到期之一触发。案例用于理解规则，不构成推荐。
