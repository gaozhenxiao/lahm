# 轻资产预收×横盘突破（asset_light_cl_base）

轻资产+合同负债扩张 + 横盘突破。

标签：`基本面` · `技术面` · `横盘` · `突破` · `合同负债`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **质量底线**：ROE ≥ **8.00%**
3. **合同负债/预收款扩张**：同比 ≥ 15.00% 或 环比 ≥ 8.00%（新准则合同负债与旧准则预收款合并口径）
4. **轻资产约束**：总资产同比 ≤ **15.00%**（或缺失视为通过）
5. **结构**：轻资产扩张约束下的合同负债/预收款扩张
6. **财务热窗**：上述财务事件发生后的 **28** 个交易日内才允许技术信号
7. **图形·横盘突破**：近 `60` 日振幅 ≤ **24.00%**，收盘突破箱体上沿，且站上均线
8. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
9. **出场（任一触发）**：止损 **−12.00%**；持有满 **40** 个交易日

信号实现：`signal_asset_light_cl_break`（`app/services/factors/signal_specs.py`）。

| 单腿涨跌 | **57.06%** |
