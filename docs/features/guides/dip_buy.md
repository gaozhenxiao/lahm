# 暴跌抄底因子（dip_buy）

做的是一件事：**跌够深、又够便宜，才买；买在当时最惨的那一侧。**

## 怎么判断

### 1. 有没有暴跌
看短中期跌幅，再加上近约 60 个交易日的回撤，合成 `crash_score`（0～1）。  
跌得越凶，分数越高。

### 2. 贵不贵（估值闸门）
用 PE / PB 相对近约 5 年历史的分位做闸门：

- 分位很高（偏贵）→ 基本不抄  
- 分位很低（偏便宜）→ 允许更高仓位  
- 中间线性过渡  

这是为了避免「高估值里接飞刀」。

### 3. 仓位怎么定
大致为：

> 仓位 ≈ 暴跌强度 × 估值允许上限 × 积极系数（默认约 1.35）

再限制在 0～1。列表里的「值」可理解为建议仓位/信号强度。

## 买什么

同时盯三个宇宙，**谁信号最强，就买谁对应的 ETF**：

| 信号指数 | 交易 ETF |
|----------|----------|
| 沪深300 | 510300 |
| 创业板 | **159915** |
| 中证500 | 510500 |

回测里空仓时段按年化约 **1.4%** 计现金收益。

记账口径：**收盘调仓**。成交参考当日收盘价；当天盈亏只算调仓前的隔夜仓，收盘新买入/加仓的部分从下一交易日起才计涨跌。  
成本：佣金万分之一（买卖）；ETF 免印花税；不计滑点。

## 和「国家队因子」有什么不同

| | 暴跌抄底 | 国家队 |
|--|----------|--------|
| 核心 | 价格恐慌 + 估值水位 | 汇金份额 / 政策动作 |
| 风格 | 逆向、偏短促 | 跟国家队节奏，可粘持 |
| 典型 | 创业板急跌且不贵 → 买 159915 | 份额抬升 / 政策火花 → 加仓时代篮子 |

## 回测大致印象（2015～2026）

- 累计收益大约 +100% 量级，CAGR 约 6%～7%  
- 夏普大约 0.65，最大回撤大约 -16%  
- **平均仓位不高**（约十几%）——平时轻仓，急跌且低估时才出手  

具体数字以列表「回测摘要」和净值图为准。
