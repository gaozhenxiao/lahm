# 现金牛回踩（cashcow_reclaim）

高净利率+估值合理，站上MA60。

标签：`自研` · `净利率` · `质量`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **估值闸门**：PE 历史分位 ≤ **55.00%**（窗口 `756` 交易日）
3. **利润率水平**：毛利率（或规则指定利润率）≥ **15.00%**
4. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
5. **动量下限**：动量指标 ≥ **-8.00%**
6. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
7. **出场（任一触发）**：止损 **−12.00%**；持有满 **25** 个交易日

信号实现：`signal_cashcow_reclaim`（`app/services/factors/signal_specs.py`）。
