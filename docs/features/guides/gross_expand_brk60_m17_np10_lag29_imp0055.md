# 毛利率扩张(突破60毛利0.17净利0.10滞后29改善0.0055)（gross_expand_brk60_m17_np10_lag29_imp0055）

毛利率扩张后突破：毛利≥17%；毛利环比升≥0.55%；净利≥10%；财务热窗29日；入场=60日高+MA20；持有51日；止损12%；无固定止盈。

标签：`基本面` · `技术面` · `毛利率` · `净利率`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **利润率改善**：毛利率/净利率环比上升 ≥ **0.55%**
3. **利润率水平**：毛利率（或规则指定利润率）≥ **17.00%**
4. **净利率过滤**：净利率 ≥ **10.00%**
5. **财务热窗**：上述财务事件发生后的 **29** 个交易日内才允许技术信号
6. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
7. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
8. **出场（任一触发）**：止损 **−12.00%**；持有满 **51** 个交易日

信号实现：`signal_gross_expand_break`（`app/services/factors/signal_specs.py`）。
