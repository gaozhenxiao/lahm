# PB低位质量突破(持有51)（pb_floor_hold51）

PB低分位质量突破 + 持有51。

标签：`基本面` · `技术面` · `估值` · `质量`

## 怎么选股（逐步）

1. **股票池**：默认 `hs300` 成分；对每只股票逐日检查，下列条件需同时满足才开仓。
2. **估值闸门**：PB 历史分位 ≤ **20.00%**（窗口 `756` 交易日）
3. **质量底线**：ROE ≥ **8.00%**
4. **图形·突破确认**：收盘 ≥ 昨日起算 **60** 日最高价，且收盘 > **MA20**
5. **组合约束**：最多同时持有 **8** 只，等权；有空位才开新仓
6. **出场（任一触发）**：止损 **−12.00%**；持有满 **51** 个交易日

信号实现：`signal_pb_floor_quality_break`（`app/services/factors/signal_specs.py`）。
