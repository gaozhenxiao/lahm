# 移动四大行网格（cm_big4_slope_grid）

对中国移动（`600941`）与工农中建（`601398` / `601939` / `601288` / `601988`）做**等权五袖口**向上倾斜网格，与策略中心「移动四大行网格」同源。

## 怎么交易

1. 资金五等分，每只股票独立跑倾斜网格  
2. 中枢 `center = max(旧, MA90)` 只升不降  
3. 相对中枢跌超 **0.8%** 加一档；涨超 **0.8%** 减一档；至少保留 **2** 档底仓  
4. 除息日按持仓份额发**现金分红**进账户，可再买网格档  
5. 空闲现金按约 **1.4%** 年化计息；卖出印花税 **千一**

共同回测起点约 **2022-01**（中国移动 A 股上市）。

## 怎么跑

```bash
python scripts/backtest_cm_big4_slope_grid.py --also-factor
```

产物：`data/strategies/cm_big4_slope_grid_*`、`data/factors/cm_big4_slope_grid_*`

## 使用建议

- 单边大涨行情里满仓持有通常跑赢网格；网格优势在回撤与夏普  
- 信号：≥3 只处于加仓区→buy；≥3 只减仓区→sell
