# 暴跌抄底因子（dip_buy）

> 因子 ID：`dip_buy`  
> 实现：`app/services/factors/dip_buy.py`  
> 刷新：`scripts/refresh_dip_buy_data.py`  
> 回测：`scripts/backtest_dip_buy_factor.py [--compare]`

## 逻辑

1. **暴跌**：短中期跌幅 + 近 60 日回撤 → `crash_score`
2. **估值闸门**：PE/PB 近约 5 年分位 → `size_cap`（高估不抄、低估加仓）
3. **仓位**：`min(1, crash×size_cap × aggression)`，默认更积极
4. **交易**：按最强宇宙买对应 ETF（510300 / **159915** / 510500）
5. **空仓利息**：默认按年化 1.4% 计入现金收益
6. **记账**：信号日收盘调仓（成交价=当日收盘）；当日策略收益只认隔夜仓，收盘新开/加仓不吃当天涨跌；净值按该日收益滚动
7. **成本**：佣金万分之一（买卖双向）；ETF 免印花税；不计滑点；换宇宙按先卖后买
